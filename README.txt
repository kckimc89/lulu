10 탐험대 V4.1

두 장의 비밀을 2판으로 변경했습니다.
1판: 1~9 중심, 1+9 / 2+8 / 3+7 / 4+6 / 5+5 총 5가지.
2판: 10부터 0까지 포함(5는 두 장), 기존 5가지 + 10과 0 조합 총 6가지.
1판과 2판을 연속으로 완료하며 전체 시간을 측정합니다.
발견한 조합은 상단에 계속 크게 표시되고, 사용된 숫자카드는 희미하게 표시됩니다.
완료 후 전체 기록/최고기록과 한 번 더 하기/다른 게임 하기가 나옵니다.
카드 모두 활용 게임은 V4의 16장·8묶음 기록도전을 유지합니다.

설치: ZIP을 풀고 index.html과 README.txt를 GitHub 저장소 최상단에 올려 기존 파일을 교체하세요.

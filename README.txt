10·100 탐험대 V5.18.2 — 성벽 쌓기 진행 오류 수정판

핵심 수정
- 기존 V5.18.1에서 숫자카드 12장을 한 번씩 소모하여 6/10에서 멈추던 오류를 수정했습니다.
- 이제 성공할 때마다 숫자카드를 새로 섞어 다시 사용할 수 있습니다.
- 따라서 완성 1/10 → 2/10 → ... → 10/10까지 반드시 진행할 수 있습니다.
- 매 라운드에는 0~10 숫자가 모두 있으므로 10이 되는 짝이 항상 여러 개 존재합니다.
- 틀렸을 때는 같은 라운드에서 다시 고를 수 있습니다.
- 성공 1회 = 10점, 10회 성공 = 정확히 100점.

성 만들기
- 성공할 때마다 성벽/탑/지붕/성문/깃발이 한 단계씩 나타납니다.
- 성 색상과 대비를 조금 강화했습니다.
- 10단계 완성 뒤 완성된 성을 크게 보여줍니다.
- '성 확인했어요'를 눌러야 기록 비교 화면으로 이동합니다.

10 탐험대 V5.2

[기록관리 강화]
- 각 게임 완료 화면에서 아이 최근 10회 / 엄마 최근 10회를 좌우로 비교
- 아이 개인 최고 / 엄마 개인 최고 / 우리집 전체 최고를 별도로 표시
- 개인 최고 갱신: 개인 최고기록 축하
- 두 사람을 통틀어 최고 갱신: '우리집 전체 최고기록'으로 가장 크게 축하
- 상대 선수 최고기록과의 시간 차이 표시
- 최근 기록 흐름도 함께 표시
- 기록은 선수별/게임별로 분리 저장

[두 장의 비밀 확장]
- '더해서 10'과 '빼서 5' 중 선택
- 더해서 10: 0+10, 1+9, 2+8, 3+7, 4+6, 5+5
- 빼서 5: 5-0, 6-1, 7-2, 8-3, 9-4, 10-5
- 두 게임 모두 0→10 / 10→0 / 랜덤 3판

[기억 속의 10]
- 큰 카드 유지: 넓은 화면 4장×3줄, 좁은 화면 3장×4줄

다음 확장 방향: 10을 이용한 두 자리 수 게임.

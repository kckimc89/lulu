루루와 마법성의 그림조각 V1 - 아이 반응 확인용 실제 게임

이번 시험판에서 실제 작동하는 것:
1. 이야기 시작
2. 숲속 숨은 그림조각 찾기
3. 오리 7마리를 4마리 정원 배로 나누어 건너기
4. 보석 5개 잡기
5. 3x3 조각그림 맞추기 (두 조각을 차례로 눌러 위치 교환)
6. 아기용 발견 및 성으로 데려오기
7. 30초 보석 챌린지 + 최고기록 저장
8. 왕관/최고기록을 iPad 브라우저에 저장
9. 홈화면 아이콘 포함

설치:
ZIP을 압축 해제하고 안의 파일 7개를 GitHub 저장소 루트에 모두 업로드/교체하세요.
Netlify 배포 후 Safari에서 열어 테스트하세요.

중요:
이번 버전의 목적은 기능을 많이 넣는 것이 아니라 아이가
- 먼저 무엇을 누르는지
- 어느 놀이에서 오래 머무는지
- 퍼즐을 다시 하려는지
- 최고기록에 다시 도전하는지
- '다음 이야기는?'이라고 묻는지
를 관찰하는 것입니다.
